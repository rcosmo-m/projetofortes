# Projeto Fortes

Projeto desenvolvido como atividade acadêmica para a disciplina da faculdade.

## 📖 Descrição

O Projeto Fortes consiste em um sistema desenvolvido para aplicar conceitos de programação e lógica computacional aprendidos durante o curso. O objetivo do projeto é implementar funcionalidades básicas de software utilizando boas práticas de organização de código.

Este projeto foi criado com finalidade educacional, visando exercitar habilidades de desenvolvimento, estruturação de código e resolução de problemas.

## 🎯 Objetivo

- Aplicar conceitos de programação aprendidos em sala de aula
- Desenvolver lógica computacional
- Trabalhar com organização de código e versionamento
- Praticar o uso do Git e GitHub

## 🛠 Tecnologias utilizadas

- Linguagem: HTML | CSS | Javascript 
- Git
- GitHub
- IDE: Visual Studio Code
